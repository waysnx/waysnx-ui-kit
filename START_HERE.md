# Start Here

### Users
Choose a package under `packages/`, read its README, then use Storybook and the WaysNX Admin Demo.

### Developers
Read `CONTRIBUTING.md`, `docs/architecture/`, and `docs/testing/`. Use Storybook during development and Playwright for browser validation.

### AI Agents
Use source code, package READMEs, WDG-generated JSON under `docs/generated/`, schemas, and specifications. Do not invent APIs or metadata.

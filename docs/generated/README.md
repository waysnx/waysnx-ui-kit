# WDG Generated Documentation

This directory contains documentation and AI knowledge generated by
WaysNX Documentation Generator (WDG) from the UI Kit source.

The generated content is derived from the source code, public exports,
Storybook metadata, component metadata, and library APIs.

Do not edit generated files manually.

To regenerate this content, use the WDG project against the corresponding
UI Kit source revision.

The generated output is committed here so that contributors, documentation
systems, and AI tooling can consume a versioned knowledge representation
directly from the public repository.

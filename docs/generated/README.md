# Generated Documentation

This directory contains documentation and machine-readable metadata generated by the WaysNX Documentation Generator (WDG).

The generated output is committed to the WaysNX UI Kit repository so that the public repository and documentation site can use a consistent, version-controlled representation of the UI Kit.

---

## Purpose

WDG generates documentation and metadata from the UI Kit source and package information.

Generated output may include information such as:

- Library metadata
- Component metadata
- Component documentation
- Relationships
- Search metadata
- Schemas
- Other documentation-related machine-readable output

The exact generated structure is determined by the current WDG output specification.

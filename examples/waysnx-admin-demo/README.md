# WaysNX Admin Demo

A small realistic enterprise application demonstrating WaysNX UI Kit as an integrated system.

## Pages
1. Dashboard
2. Complete Form — approximately 20–25 fields with validation
3. Grid Listing

## Shared Shell
Header, navigation/sidebar, user menu, language selection, light/dark mode, accessibility center, notification drawer, breadcrumbs, search and responsive behavior.

The app is also the primary integration target for Playwright.
